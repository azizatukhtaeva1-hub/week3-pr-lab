# Contributing Guide

Thank you for contributing to this project!

## Getting Started

1. Clone the repository to your computer.
2. Create a new branch for your work.
3. Make your changes or complete the assigned exercise.
4. Test your changes before submitting them.

## Branches

Create a separate branch for each task.

Example:

```bash
git checkout -b exercise-01
````

 ## Commits

 Write clear and meaningful commit messages.

 Example:

```
git commit -m "Complete exercise 01"
```

 ## Pull Requests

 When your work is ready:

 1. Push your branch to GitHub.
2. Open a Pull Request.
3. Provide a clear description of your changes.
4. Ask a classmate to review your Pull Request.
5. Read and respond to their feedback.
6. Make any necessary changes.
7. Merge the Pull Request after the review is complete.

 ## Peer Review

 When reviewing someone else's Pull Request:

 - Read the changes carefully.
- Give clear and constructive feedback.
- Mention what works well.
- Point out issues respectfully.
- Ask questions when something is unclear.

 ## Code Quality

 Keep your work:

 - Clear and easy to understand.
- Well-organized.
- Consistent with the project structure.
- Free from unnecessary changes.

 ## Questions

 If you have questions or encounter a problem, ask your instructor or classmates for help.
